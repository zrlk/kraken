# SceTest — `sce`'s pipeline on an in-memory file system (UnElab M3a)

`SceRun.run` is pure, so the whole command is tested here without I/O: every exit code (0 1 2 3 4 6), the
messages of `SceText` verbatim, import lookup (`-I`, the importer's directory), cycles and
duplicates with their notes, the `ret f(args)` lint as a warning (exit 0), `--print-elab`, `--emit-unit`,
`--check-only`, `-o`, `--help`, the `.w` mode as a normaliser (idempotent), determinism, and EM0 (
`EM0Prelude.u` then `em0.u`) through `sce` to exactly the elaborated program.  `tools/test-sce.sh` runs the real
command (`tools/sce`) end to end.
-/

def fsOf (fl : List (String × String)) : FS := fun f => match fl.find? (·.1 == f) with
  | some (_, s) => .ok s
  | none => .error s!"no such file ({f})"

  | some l => (l.drop 11).toString
  | none => "?"
